# Инженерные эксперименты

В каталоге `results` сохранены 76 воспроизводимых запусков на синтетических данных.
Каждый JSON содержит гипотезу, параметры, метрики всех кандидатов на validation,
выбранную модель, test-метрики, сравнение с baseline и диагностические срезы.

## Покрытые сценарии

- learning curve от 160 до 2 000 сессий;
- бюджет контактной очереди от 5% до 50%;
- устойчивость к разным seed генерации данных и разбиения;
- пропуски в признаках и неизвестные категориальные значения;
- сочетания размера выборки, бюджета и стресс-факторов.

## Сводка результатов

Baseline на 320 сессиях выбрал `gradient_boosting`: test PR-AUC `0.2823`,
ROC-AUC `0.5347`, F1 `0.2857`. Во всей серии test PR-AUC менялся от `0.2053`
до `0.6640`, ROC-AUC — от `0.3932` до `0.8314`, F1 — от `0.1000` до `0.5823`.

Частота выбора моделей по validation PR-AUC:

| Модель | Число запусков |
|---|---:|
| Gradient Boosting | 33 |
| Logistic Regression | 22 |
| Random Forest | 16 |
| Decision Tree | 5 |

Разброс показывает чувствительность smoke-оценки к размеру и случайности выборки.
Максимум test-метрики не используется для выбора конфигурации: это создало бы утечку
из тестовой части. Результаты предназначены для инженерной проверки pipeline и не
заменяют оценку на зафиксированной версии исходного датасета UCI.

## Повторный запуск

```bash
PYTHONPATH=src python -m online_shopper.experiment \
  --output experiments/results/example.json \
  --hypothesis "Проверить выбранный сценарий" \
  --baseline experiments/results/001_baseline.json
```
