# Данные

Основной источник — [UCI Online Shoppers Purchasing Intention Dataset](https://archive.ics.uci.edu/ml/datasets/Online%2BShoppers%2BPurchasing%2BIntention%2Bdataset). Ссылка взята из `projects.md`. Условия использования следует сверять на странице источника перед загрузкой и распространением; исходные данные в репозиторий не включаются.

Ожидается CSV с исходными признаками UCI и целью `Revenue`. Локальные CSV игнорируются Git. Для автономной проверки создайте **детерминированный синтетический smoke-набор**, который не является копией UCI:

```bash
make smoke
```

Smoke-набор нужен только для проверки кода и не подходит для содержательных выводов.
